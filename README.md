# Coding Test Curriculum

코딩 테스트를 처음 준비하는 학습자가 **12주 동안 자료구조와 알고리즘의 기초를 익히고, 제한 시간 안에 문제를 해결하는 습관**을 만드는 저장소입니다.

기존 `hackerrank/`, `leetcode/` 풀이 코드는 학습 기록으로 보존했습니다. 새 풀이는 `solutions/`에 플랫폼과 문제 번호 기준으로 정리합니다.

## 학습 대상과 목표

- 대상: Python 기본 문법을 알고 있지만 알고리즘 문제 풀이가 익숙하지 않은 학습자
- 기간: 12주
- 권장 시간: 주 6–8시간, 주 4일 이상
- 목표: 쉬운 문제를 정확히 풀고, 중간 난도 문제의 풀이 방향을 스스로 설계하기
- 최종 기준: 120분 동안 3문제 중 2문제 이상 해결

## 커리큘럼 한눈에 보기

| 주차 | 핵심 주제 | 주간 목표 |
| --- | --- | --- |
| 1주 | 복잡도, 배열, 문자열 | 입력 크기에 맞는 시간 복잡도 판단 |
| 2주 | 해시, 집합 | 빠른 조회와 빈도 계산 |
| 3주 | 스택, 큐, 덱 | LIFO/FIFO 문제 구분 |
| 4주 | 정렬, 이분 탐색 | 정렬을 전처리로 활용 |
| 5주 | 투 포인터, 슬라이딩 윈도우 | 연속 구간을 선형 시간에 탐색 |
| 6주 | 재귀, 백트래킹 | 상태 공간을 만들고 가지치기 |
| 7주 | 연결 리스트, 힙 | 포인터와 우선순위 자료구조 이해 |
| 8주 | 트리, BST | 순회와 재귀적 구조 이해 |
| 9주 | 그래프, BFS/DFS | 탐색 알고리즘을 상황에 맞게 선택 |
| 10주 | 최단 경로, 유니온 파인드, 위상 정렬 | 대표 그래프 응용 패턴 습득 |
| 11주 | 그리디, 동적 계획법 | 선택의 근거와 점화식 설명 |
| 12주 | 종합 복습, 모의 테스트 | 실전 시간 관리와 약점 보완 |

주차별 문제와 완료 기준은 [CURRICULUM.md](./CURRICULUM.md), 학습 방법은 [STUDY_GUIDE.md](./STUDY_GUIDE.md), 진도 관리는 [PROGRESS.md](./PROGRESS.md)를 참고합니다.

## 저장소 구조

```text
.
├── CURRICULUM.md          # 12주 상세 과정과 추천 문제
├── STUDY_GUIDE.md         # 풀이 루틴, 복습법, Git 사용법
├── PROGRESS.md            # 주차별 진행 체크리스트
├── notes/                 # 개념 및 오답 노트
├── solutions/             # 새 문제 풀이
│   ├── baekjoon/
│   └── leetcode/
├── templates/             # 풀이 및 오답 기록 템플릿
├── hackerrank/             # 기존 학습 기록
└── leetcode/               # 기존 학습 기록
```

새 풀이 파일은 `solutions/<플랫폼>/<문제번호>_<짧은이름>.py` 형식을 권장합니다.

## 시작하기

1. [PROGRESS.md](./PROGRESS.md)에서 시작일과 목표일을 기록합니다.
2. 1주차 진단 문제를 제한 시간 60분으로 풉니다.
3. `templates/solution.py`를 복사해 첫 풀이를 작성합니다.
4. 해결하지 못한 문제도 시도 내용과 막힌 이유를 `notes/`에 남깁니다.
5. 매주 마지막 학습일에 오답을 다시 풀고 체크리스트를 갱신합니다.

## 완료 기준

- 필수 문제 55개 이상 풀이
- 오답 문제를 힌트 없이 20개 이상 재풀이
- 시간 복잡도를 모든 풀이에 기록
- 120분 모의 테스트 3회 진행
- 마지막 두 번의 모의 테스트에서 각각 2문제 이상 해결
